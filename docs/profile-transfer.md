# Move a profile to another MasterHUB

1. Open **Profiles** in MasterDeck. Choose **Export** from the three-dot menu beside the profile you want to move. You can also open the profile and choose **Profile Settings → Use on another deck → Export**.
2. Save the `.masterdeck` file. It contains the profile, its pages, all three key gestures, and available key pictures referenced by the profile. Copy the file to the computer that runs the other deck.
3. On the destination computer, choose **Profiles → Import**. The guide lists the supported formats. Select **Choose profile file** and open your export. MasterDeck adds it as a separate profile and opens it. Check the key assignments if the decks have different modules.
4. Review the keys. Install and enable any plugins the profile uses, reconnect integrations as needed, and update actions that refer to files or apps on the first computer.

| File | What you need |
| --- | --- |
| `.masterdeck` | An export from MasterDeck with the profile and its available key pictures. Choose this when moving to another computer. |
| `.json` | A MasterDeck profile exported using **Settings only (JSON)**. It carries settings and omits picture files. |
| `.mhz` | An export made in the official Cooler Master MasterHUB app. Check the imported action assignments before using them. |

Older MasterDeck profile packages are also supported.

Review exported actions before sharing a profile with someone else, especially commands, file paths, and service addresses.
